<Tab value="Dyrected Cloud">

The fastest path to a live site. No database to configure, no storage bucket, no infrastructure.

**1. Create an account**

Sign up at [app.dyrected.com](https://app.dyrected.com), create a Workspace, then create a Site. Copy the **Site API Key** and **Site ID** from the site settings.

**2. Install**

```bash
pnpm add @dyrected/core
```

**3. Create your config**

```ts
// dyrected.config.ts
import { defineConfig } from '@dyrected/core'

export default defineConfig({
  // No db needed — Cloud manages the database
  collections: [
    {
      slug: 'posts',
      fields: [
        { name: 'title',   type: 'text',     required: true },
        { name: 'slug',    type: 'text',     required: true },
        { name: 'content', type: 'richtext' },
        { name: 'status',  type: 'select',   options: ['draft', 'published'], defaultValue: 'draft' },
      ],
    },
  ],
})
```

**4. Set environment variables**

```bash
# .env.local
DYRECTED_API_KEY=sk_live_...
DYRECTED_SITE_ID=site_...
NEXT_PUBLIC_DYRECTED_URL=https://api.dyrected.cloud
NEXT_PUBLIC_DYRECTED_SITE_ID=site_...
```

**5. Push your schema**

```bash
npx dyrected push
```

This sends your config to the Cloud, provisions the tables, and makes the API live. You must have your environment variables set for the CLI to authenticate.

**6. Fetch content**

```ts
import { createClient } from '@dyrected/sdk'

const client = createClient({
  baseUrl: process.env.NEXT_PUBLIC_DYRECTED_URL!,
  apiKey:  process.env.DYRECTED_API_KEY!,
  siteId:  process.env.DYRECTED_SITE_ID!,
})

const { docs } = await client.collection('posts').find()
```

For the full Cloud setup including router mounting and multi-site patterns, see [Deploy with Dyrected Cloud](/docs/deployment/cloud).

</Tab>
<Tab value="Next.js">

The easiest way to get started with Next.js is using the interactive CLI.

**1. Initialize**

```bash
npx dyrected init
```

Choose **Next.js** and **SQLite** (for local development). The CLI will:
- Install `@dyrected/core`, `@dyrected/next`, and `@dyrected/db-sqlite`.
- Create a `dyrected.config.ts`.
- Mount the API route at `app/dyrected/[...route]/route.ts`.
- Mount the Admin UI at `app/cms/[[...route]]/page.tsx`.
- Generate a `.env.example`.

**2. Configure and Run**

1. Copy `.env.example` to `.env` and set `DYRECTED_JWT_SECRET`.
2. Run `pnpm dev`.
3. Open `http://localhost:3000/cms` to start managing content.

</Tab>
<Tab value="Nuxt">

The easiest way to get started with Nuxt is using the interactive CLI.

**1. Initialize**

```bash
npx dyrected init
```

Choose **Nuxt 3** and **SQLite**. The CLI will:
- Install dependencies and create `dyrected.config.ts`.
- Mount the Admin UI at `pages/cms/[[...route]].vue`.
- Generate a `.env.example`.

**2. Configure and Run**

1. Add `'@dyrected/nuxt'` to your `modules` in `nuxt.config.ts`.
2. Copy `.env.example` to `.env` and set `DYRECTED_JWT_SECRET`.
3. Run `pnpm dev`.
4. Open `http://localhost:3000/cms` to start managing content.
