## Prerequisites

Before you start, ensure you have:

- [Node.js 18+](https://nodejs.org) installed
- A package manager ([pnpm](https://pnpm.io) recommended, or `npm`/`yarn`/`bun`)
- Basic familiarity with your chosen framework (Next.js or Nuxt.js)

<Tabs items={['Dyrected Cloud (SPA)', 'Next.js', 'Nuxt.js']}>
<Tab value="Dyrected Cloud (SPA)">

**SPA** stands for Single-Page Application — a client-side app that runs entirely in the browser, such as a React (Vite), Vue, or Svelte project. There is no Node.js server handling requests; your app fetches content directly from the Dyrected Cloud API using an API key.

The full Cloud setup guide — including account creation, connecting your SPA, and going live — lives at:

**[dyrected.com/guide](https://dyrected.com/guide)**

It covers React, Vue, Svelte, and more, and is kept up to date alongside the Cloud dashboard.

</Tab>
<Tab value="Next.js">

The easiest way to get started with Next.js is using the interactive CLI.

**1. Initialize**

```bash
npx @dyrected/cli init
```

The CLI auto-detects your framework from `package.json`. Choose **SQLite** for local development. It will:

- Install `@dyrected/core`, `@dyrected/next`, and `@dyrected/db-sqlite`.
- Create a `dyrected.config.ts`.
- Detect your project layout (`src/` directory, App Router vs Pages Router) and write files in the right place.
- Mount the API route at `app/dyrected/[...route]/route.ts` (or `pages/api/dyrected/[...route].ts` for Pages Router).
- Mount the Admin UI at `app/cms/page.tsx` (or `pages/cms.tsx` for Pages Router).
- Generate `instrumentation.ts` so your server logs the admin and API URLs on startup.
- Generate a `.env.example`.

**2. Configure and Run**

1. Copy `.env.example` to `.env` and fill in the values.
2. Run `pnpm dev`.
3. The admin URL is printed to the console on startup — open it to start managing content.

> **Note:** Your database schema is synced automatically on startup. No manual CLI sync is required for self-hosted projects.

</Tab>
<Tab value="Nuxt.js">

The easiest way to get started with Nuxt.js is using the interactive CLI.

**1. Initialize**

```bash
npx @dyrected/cli init
```

The CLI auto-detects your framework from `package.json`. Choose **SQLite** for local development. It will:

- Install dependencies and create `dyrected.config.ts`.
- Detect whether you use an `app/` directory and write the admin page to the correct location (`app/pages/cms/index.vue` or `pages/cms/index.vue`).
- Automatically add `@dyrected/nuxt` to `modules` in your `nuxt.config.ts`.
- Generate a `.env.example`.

**2. Configure and Run**

1. Copy `.env.example` to `.env` and configure your secrets.
2. Run `pnpm dev`.
3. The Dyrected admin and API URLs are printed to the console when the dev server starts — open the admin URL to start managing content.

> **Note:** Your database schema is synced automatically on startup. No manual CLI sync is required for self-hosted projects.

</Tab>
