## Prerequisites

Before you start, ensure you have:

- [Node.js 22+](https://nodejs.org) installed
- A package manager ([pnpm](https://pnpm.io) recommended, or `npm`/`yarn`/`bun`)
- Basic familiarity with your chosen framework (Next.js or Nuxt.js)

<Tabs items={['Dyrected Cloud (SPA)', 'Next.js', 'Nuxt.js']}>
<Tab value="Dyrected Cloud (SPA)">

**SPA** stands for Single-Page Application — a client-side app that runs entirely in the browser, such as a React (Vite), Vue, or Svelte project. There is no Node.js server handling CMS requests; your app fetches content directly from the Dyrected Cloud API using a site API key.

**1. Create a Cloud site**

Sign in to Dyrected Cloud, create a site, and keep the site settings open. You will need:

- Site ID
- Site API key
- Base URL

**2. Model the content**

Create the collections, globals, and fields your app needs in the Cloud dashboard. Use collections for repeatable content such as posts, products, events, testimonials, FAQs, or services. Use globals for one shared version of content such as navigation, footer settings, company details, or default SEO.

**3. Add starter content**

Add at least one real entry for each collection or global before connecting your frontend. This gives your app a predictable response shape while you build the UI.

**4. Install the SDK**

```bash
pnpm add @dyrected/sdk
```

Use the matching command for your package manager if you do not use pnpm.

**5. Store Cloud connection values**

Add the public Cloud values your frontend needs to `.env.local`:

```bash
VITE_DYRECTED_SITE_ID="site_..."
VITE_DYRECTED_API_KEY="..."
VITE_DYRECTED_BASE_URL="https://..."
```

Use your framework's public environment variable prefix. For example, Vite uses `VITE_`, Next.js uses `NEXT_PUBLIC_`, and SvelteKit uses `PUBLIC_`.

**6. Fetch content from Cloud**

Create one small client module for Dyrected reads and call it from your pages or components:

```ts
import { createClient } from "@dyrected/sdk";

export const dyrected = createClient({
  siteId: import.meta.env.VITE_DYRECTED_SITE_ID,
  apiKey: import.meta.env.VITE_DYRECTED_API_KEY,
  baseUrl: import.meta.env.VITE_DYRECTED_BASE_URL,
});

export async function getPosts() {
  const result = await dyrected.collection("posts").find({ depth: 0 });
  return result.docs;
}
```

**7. Render with a fallback**

Keep a small fallback state while wiring the first page so your app can render useful UI during setup or if Cloud content is temporarily empty.

**8. Go live**

Deploy through your existing host. Confirm the production environment variables match the Cloud site, then edit one piece of content in Dyrected Cloud and verify the deployed app updates.

<Tab value="Next.js">

The easiest way to get started with Next.js is using the interactive CLI.

**1. Initialize**

```bash
npx @dyrected/cli init
```

The CLI auto-detects your framework from `package.json`. Choose **Quick Setup** for SQLite + local file storage during local development. It will:

- Install `@dyrected/core`, `@dyrected/next`, `@dyrected/db-sqlite`, and `@dyrected/storage-local`.
- Create a `dyrected.config.ts`.
- Detect your App Router layout, including optional `src/` directory, and write files in the right place.
- Mount the API route at `app/dyrected/[...route]/route.ts` or `src/app/dyrected/[...route]/route.ts`.
- Mount the Admin UI at the path you choose during setup, defaulting to `app/admin/page.tsx` or `src/app/admin/page.tsx`.
- Generate `instrumentation.ts` so your server logs the admin and API URLs on startup.
- Generate a `.env.example`.

> **Note:** `@dyrected/next` requires the Next.js App Router. If your app only has the Pages Router, add an `app/` directory before running init.

**2. Configure and Run**

1. Copy `.env.example` to `.env` and fill in the values.
2. Run `pnpm dev`.
3. The admin URL is printed to the console on startup — open it to start managing content.

> **Note:** Your database schema is synced automatically on startup. No manual CLI sync is required for self-hosted projects.

</Tab>
<Tab value="Nuxt.js">

The easiest way to get started with Nuxt.js is using the interactive CLI.

**1. Initialize**

```bash
npx @dyrected/cli init
```

The CLI auto-detects your framework from `package.json`. Choose **Quick Setup** for SQLite + local file storage during local development. It will:

- Install `@dyrected/core`, `@dyrected/nuxt`, `@dyrected/db-sqlite`, and `@dyrected/storage-local`, then create `dyrected.config.ts`.
- Detect whether you use an `app/` directory and write the admin page to the path you choose during setup, defaulting to `app/pages/admin/index.vue` or `pages/admin/index.vue`.
- Automatically add `@dyrected/nuxt` to `modules` in your `nuxt.config.ts`.
- Generate a `.env.example`.

**2. Configure and Run**

1. Copy `.env.example` to `.env` and configure your secrets.
2. Run `pnpm dev`.
3. The Dyrected admin and API URLs are printed to the console when the dev server starts — open the admin URL to start managing content.

> **Note:** Your database schema is synced automatically on startup. No manual CLI sync is required for self-hosted projects.
