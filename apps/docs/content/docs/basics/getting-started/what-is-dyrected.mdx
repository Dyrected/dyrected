title: What is Dyrected?
description: Dyrected gives agencies a simple CMS dashboard for custom websites.
---

import { Card } from "@/components/ui/card";

Dyrected gives agencies a simple CMS dashboard for custom websites, so clients can safely update approved text, images, FAQs, testimonials, services, and pages without touching code or breaking the design.

You define your content model in TypeScript with collections, globals, fields, access rules, and hooks. Dyrected uses that config to generate the API, the Admin UI, and the SDK automatically. Editors can update content through a controlled admin experience while your frontend code, layout, and business logic stay in your repo.

You can run Dyrected inside a Next.js, Nuxt app, React.js app or Vue.js app, or use Dyrected Cloud for the backend while keeping the same schema in your codebase. Editors can work in Dyrected's hosted admin or in an embedded admin route inside your own app, usually at `/admin`.

Dyrected is strongest when you want developers to keep control of structure and behavior, while clients, marketers, or internal teams take over day-to-day content updates.
