title: Embedded Admin

Embedded admin means editors use Dyrected inside your own app, usually at `/admin`. This is separate from where the backend runs: you can embed the admin while using either a Dyrected Cloud backend or a self-hosted backend.

Choose embedded admin when you want the client or team to manage content from your own domain. Choose the hosted admin at `app.dyrected.com` when you want Dyrected to handle admin updates for you.

This is perfect for:
- Giving clients a white-labeled dashboard under your own domain.
- Building custom administrative workflows alongside the CMS.
- Deploying a "Single Page App" (SPA) dashboard with zero backend requirements.

## Update ownership

When you embed the admin, the admin UI becomes part of your app package and deployment flow.

- **Hosted admin** updates are managed by Dyrected
- **Embedded admin** updates ship when you update packages and deploy your app
- **Backend upgrades** still depend on whether you use the Cloud backend or a self-hosted backend

## React Integration

If you're using React (Vite, CRA, or custom), you can use the `@dyrected/admin` component directly.

### 1. Install

```bash
pnpm add @dyrected/admin @dyrected/core
```

### 2. Create an Admin Page

Create a catch-all route (e.g., `/admin/*`) and mount the `AdminUI` component.

```tsx
import { AdminUI } from '@dyrected/admin'
import '@dyrected/admin/styles' // Don't forget the styles!

export default function MyDashboard() {
  return (
    <div style={{ height: '100vh' }}>
      <AdminUI 
        apiKey={process.env.DYRECTED_API_KEY}
        siteId={process.env.DYRECTED_SITE_ID}
        baseUrl="https://api.dyrected.cloud" // Or your self-hosted URL
      />
    </div>
  )
}
```

## Vue / Nuxt.js Integration

Since the Admin UI is built with React, we provide a `renderAdminUI` helper that works in any environment, including Vue.

### 1. Install

```bash
pnpm add @dyrected/admin
```

### 2. Create a Component

You can mount the React application inside a Vue `ref`.

```vue
<template>
  <div ref="adminContainer" class="admin-wrapper" />
</template>

<script setup>
import { ref, onMounted, onUnmounted } from 'vue'
import { renderAdminUI } from '@dyrected/admin'
import '@dyrected/admin/styles'

const adminContainer = ref(null)
let cleanup = null

onMounted(() => {
  if (adminContainer.value) {
    cleanup = renderAdminUI(adminContainer.value, {
      apiKey: 'your-api-key',
      siteId: 'your-site-id',
      baseUrl: 'https://api.dyrected.cloud'
    })
  }
})

onUnmounted(() => {
  if (cleanup) cleanup()
})
</script>

<style scoped>
.admin-wrapper {
  height: 100vh;
}
</style>
```

## How it Works

The Admin UI package is a standalone application that communicates with the Dyrected API via HTTP. 

- **No Server Needed for the Admin UI**: You can host this dashboard as a static site on Vercel, Netlify, or even GitHub Pages while still pointing it at a Cloud or self-hosted backend.
- **Auto-Sync**: In **Self-Hosted** mode, the UI reflects changes as soon as you save your `dyrected.config.ts`. In **Cloud** mode, run `npx @dyrected/cli sync:schema` to push your local changes to the cloud API.
- **Authentication**: By default, the UI handles its own login state, securely storing the session token in the browser.

## Configuration Props

| Prop | Type | Description |
|---|---|---|
| `apiKey` | `string` | Your Site API Key. |
| `siteId` | `string` | Your Site ID. |
| `baseUrl` | `string` | The API endpoint (Defaults to Dyrected Cloud). |
| `onNavigate` | `function` | Optional callback to sync route changes with your host router. |
