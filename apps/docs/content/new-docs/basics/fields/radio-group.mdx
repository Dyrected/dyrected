---
title: Radio Group
description: A single choice from a small set of options, shown as radio buttons.
---

The radio field is like a [Select](/new-docs/basics/fields/select), but it shows every option at once as radio buttons. Use it when the set of choices is small and you want editors to see all options without opening a dropdown.

```ts
defineRadioField({
  name: 'layout',
  label: 'Layout',
  options: [
    { label: 'Standard', value: 'standard' },
    { label: 'Wide', value: 'wide' },
  ],
})
```
