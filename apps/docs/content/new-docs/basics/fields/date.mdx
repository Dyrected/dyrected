The date field stores a calendar day and shows editors a date picker. Dates cross the API as ISO strings, so parse them at your application boundary when you need to do date arithmetic. When you also need a time, reach for [Date and Time](/new-docs/basics/fields/datetime); for a time of day on its own, use [Time](/new-docs/basics/fields/time).

```ts
defineDateField({ name: 'publishedAt', label: 'Published at' })
```
