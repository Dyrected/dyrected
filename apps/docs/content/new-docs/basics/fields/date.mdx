title: Date
description: A field for dates and times, stored as an ISO string and shown with a picker.
---

The date field stores a point in time and shows editors a date or date-and-time picker. Dates cross the API as ISO strings, so parse them at your application boundary when you need to do date arithmetic. Related `datetime` and `time` types cover finer-grained needs.

```ts
defineDateField({ name: 'publishedAt', label: 'Published at' })
```
