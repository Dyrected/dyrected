The rich text field stores formatted content — headings, bold, links, lists, and embedded blocks — as structured JSON rather than an HTML string. Render it on your frontend with the Dyrected converters. Reach for it whenever content needs real formatting instead of plain text.

```ts
{ name: 'body', type: 'richText', label: 'Body' }
```
