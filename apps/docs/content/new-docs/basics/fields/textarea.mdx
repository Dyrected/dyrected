The textarea field stores multiple lines of plain text. Use it for summaries, descriptions, and other longer content that does not need formatting. When you need bold, links, or headings, use [Rich Text](/new-docs/basics/fields/rich-text) instead.

```ts
defineTextareaField({ name: 'excerpt', label: 'Excerpt' })
```
