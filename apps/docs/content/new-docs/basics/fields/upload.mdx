The upload field references a document in an upload-enabled collection, such as your media library. Use it for images, documents, and other files. The referenced document exposes a resolved `url` you consume directly rather than reconstructing storage paths. See [Storage Adapters](/new-docs/features/upload/storage-adapters) for where those files live.

```ts
defineImageField({
  name: 'coverImage',
  label: 'Cover image',
  relationTo: 'media',
})
```
