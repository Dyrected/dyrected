When a collection enables uploads, Dyrected needs somewhere to put the files. That is the storage adapter's job. You pass it as the `storage` key in `dyrected.config.ts`, and Dyrected uses it whenever an upload document is created, read, or deleted. In Dyrected Cloud, storage is managed for you.

```ts
import { defineConfig } from '@dyrected/core'
import { S3Adapter } from '@dyrected/storage-s3'

export default defineConfig({
  storage: new S3Adapter({ bucket: process.env.S3_BUCKET! }),
  collections: [Media],
  globals: [],
})
```

## What a storage adapter does

A storage adapter persists file bytes and resolves the public URL that upload documents expose through `doc.url`. Always consume that resolved URL rather than reconstructing storage paths yourself — local storage serves bytes through the app, while cloud adapters usually return a provider or CDN URL.

Image-enabled uploads can also use an image service to generate the resized variants defined by a collection's `imageSizes`.

## Choosing storage

Use local disk for development and single-node deployments, and an object-store adapter such as S3 for production and multi-instance deployments where files must be shared across servers.

## StorageAdapter

The interface every storage adapter must implement.

Dyrected ships adapters for local disk, S3, Cloudflare R2, Cloudinary, and
Backblaze B2. Implement this interface to use any other storage provider.

```ts
export interface StorageAdapter {
  /**
   * Upload a file and return its metadata (URL, dimensions, etc.).
   * The `prefix` is a path prefix used for multi-tenant setups.
   */
  upload(args: { filename: string; buffer: Uint8Array; mimeType: string; prefix?: string }): Promise<FileData>;

  /** Delete a file by its stored filename. */
  delete(args: { filename: string }): Promise<void>;

  /** Return the public URL for a stored file. */
  getURL(args: { filename: string }): string;

  /**
   * Retrieve the file's raw bytes and MIME type for serving via the API.
   * Only needed by adapters that serve files through the Dyrected API
   * (e.g. `LocalStorage`). Cloud adapters return `null` here and rely on
   * direct CDN URLs instead.
   */
  resolve?(args: { filename: string }): Promise<{ buffer: Uint8Array; mimeType: string } | null>;
}
```

| --- | --- |
| <code>upload</code> (optional) | Upload a file and return its metadata (URL, dimensions, etc.). The &#96;prefix&#96; is a path prefix used for multi-tenant setups. |

| <code>getURL</code> (required) | Return the public URL for a stored file. |
