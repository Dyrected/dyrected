# @dyrected/react

The official React SDK for Dyrected. Provides hooks and components for integrating Dyrected into React and Next.js applications.

## Installation

```bash
npm install @dyrected/react @dyrected/sdk
```

## Features

- **Live Preview**: `useLivePreview` hook for real-time content editing.
- **Provider Pattern**: `DyrectedProvider` for sharing the SDK client across your app.
- **Hooks**: `useDyrected` for easy access to the client.
- **Type Safe**: Fully written in TypeScript.
